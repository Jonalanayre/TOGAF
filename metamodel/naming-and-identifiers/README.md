# Naming and identifiers

Use lowercase kebab-case filenames or subject folders. Each subject folder can use README.md as its main record.

Optional IDs help when names change: APP-001 for applications, INT-001 for integrations, CAP-001 for capabilities, DATA-001 for data, INIT-001 for initiatives, and ADR-001 for decisions. If used, keep IDs unique and never reuse them. IDs are not required to begin writing documentation.

Use YYYY-MM-DD dates. Documentation can be Draft, Verified, or Deprecated. State Current or Proposed separately; a verified proposal is still a proposal.
