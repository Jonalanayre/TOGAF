# Relationships

Use normal Markdown links, with a short explanation of each connection. No special syntax or software is required.

| From | Relationship | To |
| --- | --- | --- |
| Organization | Accountable for | Capability or process |
| Process | Realizes | Capability |
| Application | Supports | Capability or process |
| Application service | Provided by | Application |
| Application | Uses | Data entity |
| Integration | Connects | Source and target applications |
| Integration | Exchanges | Data entities |
| Application | Depends on | Technology components or services |
| Component | Operates in | Environment |
| Initiative | Changes | Affected architecture records |
| Decision | Explains a choice affecting | Relevant records |

These are local documentation conventions, not a formal modeling-language specification. Keep facts in one record and link them. Reverse indexes are optional and manually maintained.
